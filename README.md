# Reaz Mahamud Joy — Portfolio

A clean, responsive personal portfolio website built with pure HTML, CSS, and a little vanilla JavaScript. No frameworks, no build step — just open `index.html`.

**Live site:** https://joy944243-dev.github.io/joy-portfolio/

## About

Portfolio of **Reaz Mahamud Joy** — focused on working with AI tools, learning new technology, writing, and editing (documents, images, and video).

## Features

- **Dark / Light theme toggle** — saved in `localStorage`, so the choice persists between visits
- **Animated background** — floating gradient orbs with a subtle grid overlay
- **Services** — AI content & editing and 1-year home tuition experience
- **Photo Gallery** — 16 nature & animal photos with a click-to-zoom lightbox
- **Video section** — HTML5 player with poster image and metadata
- **Cat Gallery** — 10 cat photos, same lightbox experience
- **Personal info & contact** — phone link, location, and downloadable CV (PDF)
- **Fully responsive** — mobile-first layout with a collapsible hamburger menu, fluid grids, and touch-friendly spacing
- **Lazy-loaded images** — fast first paint on slow connections

## Run Locally

```bash
git clone https://github.com/joy944243-dev/joy-portfolio.git
cd joy-portfolio
# then just open index.html in a browser
```

Or serve it with any static server:

```bash
python -m http.server 8000
```

## Deploy

Hosted with **GitHub Pages** from the `master` branch (root folder). Every push to `master` updates the live site automatically.
